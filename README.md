# 📚 Programação Orientada a Objetos em Java

Estudos de POO em Java feitos entre setembro e outubro de 2023, com uma aula por pasta.

| Pasta | Tema | Exemplo |
|---|---|---|
| `Projeto Java/Aula02` | Classes, atributos e objetos | `Celular` |
| `Projeto Java/aula03` | Métodos com parâmetros e retorno | `Personagem`, que calcula o dano de um ataque com um dado |
| `Projeto Java/Aula04` | Pacotes | `br.com.devflix`, com as classes de vídeo (filme, série, novela, documentário) e as de interface |
| `Projeto Java/Aula05` | Modificadores de acesso | `FestaVip` |

## Como rodar

Cada pasta é um projeto Java independente, no formato do VS Code. Abra a pasta da aula no VS Code com a extensão de Java e execute o `App.java`.
